# 充电热实验：公开数据准备结果

日期：2026-10-07（新加坡时间）。状态：已下载、校验、解析并准备候选数据；未标定物理模型，未训练神经网络。

## 1. 数据路线结论

导师不提供数据后，本轮转向公开实测资料。已取得一个可开展最小热预测实验的候选主数据源：KU Leuven / EnergyVille 的真实车辆快充数据。温度对象是 **BMS 报告的电池包最高温度**，不是充电功率模块散热器温度。

Journal 1 没有定义测温部件，但之前最小计划优先考虑模块散热器。采用当前公开数据时，应把实验明确具体化为“不同快充功率下的电池包温度预测”，在最终材料中记录对象变化；它不构成 Deye 模块、整桩或认证级热安全验证。当前数据足够准备电池包温度原型；导师是否认可该对象覆盖原定热主线，仍需后续范围反馈。

目前不需要用户手动下载。原文件、来源元数据、校验记录、数据字典和下载入口均已保存于 `Thermal_Prediction/`。

## 2. 实际检索与文件检查

| 数据源 | 实际检查结果 | 使用决定 |
|---|---|---|
| [KU Leuven BEV energy dynamics](https://doi.org/10.48804/8KPDTW) | V2 ZIP 已完整下载，162,310,975 bytes；通过发布者 MD5，保存 SHA256；读取所有25个快充 CSV | 候选主数据；CC-BY-4.0，最终报告引用数据作者和论文 |
| [TU Dortmund EV charging profiles](https://zenodo.org/records/14065331) | 字典声明 CCS 正/负极温度；实际提取28个 CCS 单向 DC 合并文件和23个 EV-Monitor 原始文件，各成员通过 ZIP CRC；不是完整 ZIP 校验 | 不采用为 CCS 热预测主数据，原因见下文 |
| [KU Leuven 充电效率数据](https://doi.org/10.48804/C5PT0R) | 已核查官方文件清单；体量小但包含图表及少量原始记录 | 未下载；已有更充分主候选，无需堆积数据 |
| NASA / MATR / CALCE | 之前仅完成来源调研；本轮没有再下载 | 暂不需要，避免扩展电芯寿命实验 |

TU Dortmund 的关键问题：下载的28个 CCS 单向 DC 合并文件不含目标连接器温度列；23个含 CCS 温度的 EV-Monitor 文件全部属于 Mitsubishi Eclipse Cross。其 CCS 电流绝对值最大0.1 A，CHAdeMO 电流绝对值最大27.92 A；车辆和接口元数据也标明该车走 CHAdeMO。因此这些 CCS 温度记录不能作为被充电 CCS 接点发热的有效验证标签。字典存在目标字段并不证明适用。

该判断只覆盖已下载子集及检查过的压缩包目录，不宣称整个公开领域都没有可用模块温度数据。

| 预备训练 / 验证 / 测试运行 | 14 / 4 / 7 |
| 对应有效记录数 | 24,916 / 9,911 / 8,347 |

清洗规则：要求时间、目标温度、环境温度、DC电压和电流有效；不依据温度高低或未来预测误差删样本；不插值温度真值；任何不是连续1秒的间隔划为新段，窗口不得跨段。同一车辆同一 UTC 日期的运行在同一个集合，避免同日多次快充被拆分到训练与测试。

原始文件中的缺失时间多次出现，最初可表现为重复空时间；剔除无效记录后没有重复有效时间。不能把这些空时间称为真实重复观测。

温度为 BMS 聚合最高温度，并非固定位置热电偶，最高温度对应的部位可能变化。DBC 定义的该信号分辨率为0.25 °C；训练数据相邻1秒温度变化的中位数和95分位数均为0，短时温度保持基线可能较强。不能仅靠大量重叠窗口夸大独立样本量。

## 4. 字段与功率分档

| 统一字段 | 原始字段 / 来源 | 单位与使用边界 |
|---|---|---|
| timestamp_utc | Timestamp | 解析为带时区 UTC，原文件保留 |
| temperature_c | BMSmaxPackTemperature | °C；主预测标签 |
| ambient_c | VCFRONT_tempAmbient | °C；外部环境信号，不能替代冷却液温度 |
| dc_current_a / dc_voltage_v | FC_dcCurrent / FC_dcVoltage | A / V；本轮所读快充段相乘功率非负 |
| dc_power_w | DC电流 × DC电压 | W；充电输入，不是全部发热功率 |
| battery_current_a / battery_voltage_v | RawBattCurrent132 / BattVoltage132 | A / V；保留原符号，未拿其绝对值冒充热源 |
| soc_percent | SOCave292 | %；状态特征候选 |
| bms_dissipation_kw | BMSdissipation312 | DBC 标为电池耗散；含义与热管理作用仍需进一步核查，暂不直接当物理热源 |
| preconditioning_request | UI_batteryPreconditioningRequest | 预热请求信号候选，不等于完整冷却状态 |

只用训练集合中大于1 kW的 DC 功率三分位建立候选分档：低功率约1–68.84 kW，中功率约68.84–94.67 kW，高功率大于94.67 kW；不超过1 kW单独标为低流量/停充候选。这是数据驱动的功率分组，不等于实验室控制的三种独立协议。

训练、验证和测试均有低/中/高功率记录；测试低/中/高分别覆盖7/6/5个运行，验证各档均覆盖4个运行。这些运行可以跨多个档位，不能把各档运行数相加当总运行数。完整证据在 `results/preparation/power_coverage.csv`。

## 5. 后续最小实验设定

保留三个模型：温度保持、有效 RC、RC + 小型 MLP。暂用过去60秒预测未来60秒，正式窗口采样方式和步长在建模前冻结。

当前数据没有已核实的可预先获得的未来充电计划，因此主实验采用起点负载保持假设；各模型使用相同输入，不读取未来实际功率。环境温度短时保持起点值。若增加未来实际负载实验，应单独称为回顾性条件预测。

电池路线的物理模型须改为有效热响应模型，例如有效电流平方热源加环境散热；不能原样照搬模块效率损耗模型，也不能把 VI 全部当热源。主动冷却、预热、SOC及最高温度聚合均可能造成模型偏差，需要写入假设和残差分析。没有完整热管理信号，不宣称辨识真实电池热阻、热容或控制策略。

本轮划分和功率阈值是预备协议，尚未用于调参或模型评价。物理标定、预测样本构建、指标和模型权重仍待下一阶段完成。只做数据准备，不报告模型效果。
